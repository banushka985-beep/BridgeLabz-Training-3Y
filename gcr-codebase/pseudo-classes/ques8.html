Box-Sizing Comparison

Same width and padding, two different sizing rules.

content-box (default)

width: 200px + padding: 20px adds up, so this box renders wider than 200px in total.

border-box

width: 200px already includes the padding, so this box stays exactly 200px wide.

With the default content-box, padding and border are added on top of the declared width, making the element grow larger than expected. With box-sizing: border-box, padding and border are included inside the declared width, so the total size stays predictable.

Resize the window to see both boxes remain centered and responsive.
